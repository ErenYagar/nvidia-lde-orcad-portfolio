# Claim / evidence matrix

Status vocabulary: `VERIFIED` = directly supported by a current repository artifact; `PRELIMINARY` = design intent or review evidence, not a released qualification; `SIMULATION-LIMITED` = a recorded simulation result with model/runtime boundary; `BLOCKED` = a required input or gate is missing; `OPEN` = not yet measured or not concluded.

| Architecture B is 12 V slot input → eFuse → synchronous buck → shunt → 3.3 V SSD | PRELIMINARY | Shows the power trade-off and review boundary | [`docs/architecture_tradeoff.md`](architecture_tradeoff.md), [`docs/system_block_diagram.md`](system_block_diagram.md) | Selected topology and rationale | Closed component settings or bench power performance |
