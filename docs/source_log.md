## Source review 規則

1. 網頁摘要、distributor page、forum 或搜尋結果不得單獨關閉 critical requirement。
2. Datasheet 必須記錄 document number、revision、下載日期與檔案 hash；本表 URL 只是入口。
3. Pin mapping 至少需要 governing specification 與第二份公開原廠設計交叉檢查；若兩者衝突，以 governing specification 為準並建立 review issue。
4. NVIDIA 公開設計只作方法與 implementation cross-check，不複製 NVIDIA 專有設計，也不取代 PCI-SIG／M.2 governing specification。
5. JLCPCB stack-up 是動態製程資料；release 時必須保存實際 quote／calculator evidence，不以本表存取日期當成製造確認。
6. 搜尋不到 exact connector／shunt drawing 時，維持 `Pending_Human_Verification`，不得從相近料號推導 land pattern。
