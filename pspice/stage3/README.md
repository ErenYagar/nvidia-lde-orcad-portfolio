# Stage 3 PSpice power closure

`pw01_recovery_closure_132u_8p2.cir` reruns the exact Stage 2 combined
startup/5 A/7 A/recovery profile with a 132 uF effective output-capacitance
corner and 3 mOhm aggregate ESR.

The value is a simulation candidate, not a released BOM value. It requires
capacitor part-number selection, DC-bias/temperature/tolerance evidence and
layout-parasitic correlation before power design freeze.
